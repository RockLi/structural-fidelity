brian2-atlas 异质 LIF 与嵌套长时域：小型外部检验
2026-11-09；独立新增实验，未改动冻结 preprint

一、结论

本次在已发布 brian2-atlas 0.2.0 的原生 reference-f64 后端完成了异质电流型 LIF 检验。没有安装或调用 upstream Brian2 分发包。Atlas 使用 brian2 命名空间提供前端；运行器确为安装包内的 b2-runner，版本、安装来源、模型与二进制哈希均保存。

短时域的“匹配总驱动仍不足以决定结构修改的脉冲可见性”在这个新内核中复现；但长时域不能继续用切换数作为唯一头条：到 300 ms，异质组所有交换在所有输入下都已出现逐单元脉冲差异，切换数因此为零。

安全方向排序提供了更有区分力的补充：使用自身输入参考轨迹优于冻结全局输入后迁移，然而自身评分也随时域延长而下降，且不稳定胜过所有简单对照。认证区域仍能成立，但半径明显缩小。结果支持把输入、时域和具体读出同时写入保真主张，不能把某个短窗切换比例当作网络不变属性。

这增加了超出旧同步核的外部证据，同时给出明确失效边界。它没有建立跨所有 IF 模型、噪声条件、无限时域的普适规律，也没有证明评分的计算优势。

二、固定设计与执行

图：沿用三种生成规则各一张现有原图：seed100（E/I 独立边）、201（模块亲和）、301（环形距离亲和），各带 19 个原有合法双边交换。没有增加原图种子或重新挑交换。

网络：125 块 × 4 单元 = 500 个实际 LIF 单元。每条块边展开为 16 条单位间边，单位权重为归档块权重 × 0.001/4 V。均匀延迟 0.1 ms。变量 ge/gi 表示电流等效电压贡献，不是带反转电位的电导模型。

配对控制：hom 组所有单元 tau_m=20 ms、阈值 −50 mV；hetero 组每块各有四个 18–22 ms 的 tau_m 和四个 −51 至 −49 mV 的阈值，按预定种子独立置换。两组其余设置相同。初始/重置 −60 mV，静息 −65 mV，背景等效驱动 18 mV，兴奋/抑制电流时间常数 5/10 ms，Euler dt=0.1 ms，不应期 2 ms；不应期钳制电压，电流继续衰减和接收输入。所有组都使用各自原图、各自输入的参考轨迹。

输入：沿用 G_B、F_B、F_H、G_T、F_HT 的支持与时间掩码。驱动幅度固定为二进制可精确表示的 15.625/78.125 mV。G_B/F_H、G_T/F_HT 每个时间槽的全网总驱动相同。G_B/G_T 与 F_H/F_HT 每节点幅度多重集在完整 30 ms 周期内相同。重复十个周期至 300 ms，并读取同一轨迹的 30/100/300 ms 前缀；100 ms 包含不完整周期，不能声称该前缀的每节点幅度多重集匹配。

600 条正式网络轨迹 = 3 图 × 2 模型 × 5 输入 × 20 图；三个时域是重复测量，不是 1,800 个独立试验。另有 90 次原图重复/独立短时域复核、一条保留的早期技术重复，以及 89 次完整 Atlas 区域端点/失效见证核验。

方向：每图预选目标对索引 0、9、18，每对沿用 16 个固定支持联合权重方向。共 4,320 个方向×模型×图×输入×时域条件。评分、选择规则和搜索预算在半径查询前锁定。区域参数为一个共同 binary64 alpha，所有选中权重按 RN(w*RN(1+sign*alpha)) 改变，最大对称半径 0.25；这不是交换图认证，也不是图压缩。

本地协议/hash 锁定不是外部注册。小型技术样例用于核查 Atlas 导出与调度；正式运行中发生的适配器修复保留日志，没有根据科学结果调整模型、输入、搜索条件或选择规则。日期及锁定历史见 PROTOCOL.txt、protocol-lock.json、design-lock*.json、score-lock.json 和 preflight/。

三、可见性：短窗复现，长窗二值读出饱和

每格为 19 个固定交换中，在两个输入间“逐单元逐槽完全相同/不同”发生切换的数目。三个数字依次为 seed100/201/301。

比较                         hetero 30 ms    hetero 100 ms   hetero 300 ms
G_B / F_H，逐槽总驱动匹配       7 / 8 / 9       0 / 1 / 0       0 / 0 / 0
G_T / F_HT，重排后总驱动匹配    13 / 10 / 11     0 / 0 / 0       0 / 0 / 0
G_B / G_T，全局时间重排         11 / 8 / 7       0 / 1 / 0       0 / 0 / 0
F_H / F_HT，焦点时间重排         5 / 0 / 3       0 / 0 / 0       0 / 0 / 0
F_B / F_H，同支持改驱动量         2 / 3 / 3       1 / 0 / 0       0 / 0 / 0

同质对照 G_B/F_H 的切换数：30 ms 为 4/5/6；100 ms 为 7/4/4；300 ms 为 2/1/1。

必须保留的负结果：hetero 的 seed201 在 30 ms 的焦点时间重排对照中就是 0/19；不能写成所有输入比较都出现切换。异质组到 300 ms，三图、五输入、所有 19 个交换均已不同于各自原图，因此全部五种输入比较都是“两边都不同”。零切换不能被解释为输入不重要，更不能被解释为轨迹恢复一致。图 visibility-saturation 展示完整三类构成，而不仅画切换曲线。

确有异质性和持续活动：hetero 300 ms 中，116–125/125 个块的内部单元脉冲序列不同；401–500/500 单元有发放；平均发放率 21.59–40.36 Hz，后 100 ms 仍有 1,069–1,934 个脉冲。hom 块内始终同步，平均率 21.76–39.52 Hz。异质参考轨迹记录到的最小电压为 −60 mV，没有复现旧核数千负电压的尺度问题。这只验证本次工作负载，不等于普遍生物真实性。

同时保存逐单元和块计数误差；本批没有“逐单元变了但整个块逐槽计数完全相同”的案例。误差幅度、首次分歧时间和计数累计分解均保存在 swap-errors.csv，未把二值切换当成唯一动力学量。

四、评分：自身参考有用，但长时域和对照边界明显

F_H 条件的宏排序一致率（先在每个可分辨目标对内计算，再对目标对宏平均）。每格按 seed100/201/301 顺序。只比较认证下界与实际失败上界严格分离的方向对；所有评分共用同一可分辨集合。

异质组       自身 F_H 联合评分          冻结 G_B 联合评分          可分辨覆盖率
30 ms        .994 / 1.000 / .995        .734 / .584 / .567         41.7 / 76.7 / 60.3%
100 ms       .850 / .914 / .813         .495 / .531 / .570         85.6 / 97.2 / 95.6%
300 ms       .775 / .826 / .753         .526 / .585 / .545         71.9 / 95.6 / 75.3%

30 ms 的 seed100 和 seed301 只有 2/3 个目标对进入宏平均；seed201 为 3/3。100/300 ms 均为 3/3。未分辨方向、上限截断、静默目标没有被换样；全部 270 个目标对×图×模型×输入×时域组中有 29 个目标脉冲总数为零，具体覆盖见 ranking-coverage.csv。

不能照搬旧结论“冻结评分总是接近随机”：新 LIF 在 30 ms 的 seed100 冻结评分仍有 .734，一部分排序可迁移；较长时域才更接近 .5。本研究也没有做等价性检验来断言等于随机。

因子消融也不支持万能评分。异质 F_H 300 ms 的联合 / 仅滤波 / 仅裕度 / 平均活动 / 时间打乱为：
seed100: .775 / .740 / .581 / .740 / .676
seed201: .826 / .768 / .562 / .774 / .748
seed301: .753 / .690 / .560 / .753 / .759
环形图的联合评分与平均活动打平，略低于打乱。全 frozen-branch 导数比较器也没有保持恒为 1，不能将它包装成独立预测发现。

区间分离程度：异质 F_H 300 ms，已分辨方向对按“较大下界/较小失败上界”的保证比值分为 [1,1.25)、[1.25,2)、[2,∞)，联合评分的微平均一致率为 .676/.729/.863（136/321/417 对）。这是相关配对的描述性细分，不是独立样本置信区间；近半径难对确实更难。主表依然使用宏平均，没有以这一微平均替换。

冻结 G_B 选择的方向在 F_H 下也不是必然失败。异质 300 ms，9 个图×目标对上，对 random 的“胜/负/相同方向/未分辨”为 4/3/0/2，对 mean 为 4/1/3/1，对 shuffle 为 5/3/0/1。样本很小且相依，不支持稳定优越或稳定劣势的概括。

事后实现诊断：预定评分使用 max(|阈值裕度|, 2^-20 V) 作为分母。异质 30/100/300 ms，45 个目标对×图×输入组中有 15/34/45 组触及该下限。长窗所有组都有至少一个被截断的裕度。因此评分下降不能仅归因于某个生理机制；固定数值正则项也是边界。本次没有取消下限、重新调参或另选结果更好的评分。posthoc-margin-floor-audit.csv 仅记录这一诊断，不参与选择或认证。

五、区域认证：覆盖成立，半径依赖时域，零下界须准确解释

新 binary64 仿射/区间包络纳入电流衰减、精确投递序、每个受影响单元的电压、重置和不应期。证书保证本次有限前缀内每单元每槽脉冲相同，不保证连续状态相同。完整条件和逐步误差界见 THEORY.txt；不是把旧 binary32 证明直接迁来。

总计 4,308/4,320 个条件得到正认证下界，且这 4,308 个条件均实际包含至少三个不同的浮点权重事件向量与三个不同的端点连续状态路径（alpha=−L,0,+L）。剩余 12 个均为 seed301/hetero/F_H/目标对18/300 ms，区间为 [0,2^-20]，在预定绝对宽度容差处停止；上端已有独立回放的脉冲失效见证。它们不是“零半径证书失败”，也不能说明不存在更小正安全区域，更不能混入正覆盖数。

停止分类：3,477 个达到宽度容差，832 个认证至 25% 上限，11 个到达 8 次细化预算；没有 proof_gap 或 zero_guard 停止。12 个零下界包含在“达到容差”的计数中。全部 1,440 个跨时域嵌套方向族的已获得下界均非增；这是本次数值结果。真正的有限前缀安全集必然嵌套，但算法下界并非真实最大安全半径。

归零组最小参考裕度约 2.03e-10 V，低于固定评分下限 9.54e-7 V。它说明极细阈值事件会限制逐 spike 完全相同的区域；不能据此声称混沌、不稳定平衡或所有 LIF 都如此。

认证率不是旧 17 个交换案例的跨模型成功率。这里认证的是固定连接支持下的联合权重方向族，不能将 4,308/4,320 与旧 16/17 拼成同一分母。

六、实现验证与可复现性

1. 包隔离：venv 中 brian2-atlas==0.2.0；没有 upstream Brian2 distribution。所有正式网络执行使用其原生 b2-runner。绘图环境只读 CSV，不执行仿真。
2. 30 条原图参考、全部 500 单元、全部 3,000 槽，共 135,000,000 个 v/ge/gi 状态字与独立 C 回放逐位相同；脉冲也完全一致。没有用一个代表单元替代异质块。
3. 90 次重复/短前缀检查全部通过；另保留并核对早期技术重复一条。
4. 所有认证下界的 −L、0、+L 通过回放及包络检查，共 445,824,000 个端点状态值。固定 pair0/direction0 的各图、模型、输入、时域执行独立 Fraction 逐操作核查：688,770 次精确有理数舍入操作，261,360 个精确仿射包含检查。这些抽查验证实现，不替代全参数区间的数学推导。
5. 60 个安全端点和 29 个失效见证在完整 Atlas 网络复核；全部与局部回放的相等性/首次分歧时刻一致。上限内没有失败见证的条件未人为寻找更大半径。
6. 所有 57 个继承交换逐节点、分 arm 的入出度与权重多重集相同，且恰移除/新增两条邻接；原图数据没有改写。
7. 4,320 条评分的锁定哈希及 24,464 个可分辨配对判定二次核查；固定首目标对、方向0的90个条件另用事件流、闭式卷积和原生仿射系数核查5种评分。全部旧 preprint DOCX/PDF、旧复现 ZIP 和前两批实验 MANIFEST 哈希不变。
8. 汇总、原始压缩轨迹、模型 JSON、源代码、锁定记录、失败日志及完整 Atlas 复核记录都在本目录。没有把 Python 包装计时作为计算性能贡献。

七、对科学主张和后续写作的判断

可以加强：总驱动匹配不能决定结构可见性，已不局限于旧同步数值核；输入自身参考对安全方向排序的重要性，在具有不同单元参数和正常活动尺度的 LIF 上仍能观察到；固定支持权重族的有限时域证书确实可在新 arithmetic/scheduler 下实现并核验。

必须收紧：二值可见性切换率有强时域依赖，长窗可能因“两边都变了”而消失；安全区域和评分并不随观察时间稳定；冻结评分并非每个短窗都随机，联合评分也并非总胜过平均或打乱对照。评分的固定裕度下限会影响极细阈值附近的排序。

未解决：每种新图规则仅一张图、一个 LIF 参数配置、固定 dt、无噪声；块间投射仍共享广播输入，四个异质单元并不等于任意微观异质连接；300 ms 是相对旧窗口延长十倍的有限时域，不是渐近保证；重复30 ms输入不能代表全部长期刺激类型。异质与同质的配对只隔离本次参数异质性的影响，旧核与 LIF 的绝对数值差异还包含许多建模变化。

值得纳入后续 preprint 的是“独立核下的条件性复现及长时域边界”，而不是把所有指标写成成功复制。本次先完成实验和分析；冻结稿、中英文文件及旧复现包均未修改。
